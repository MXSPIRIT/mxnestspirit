# Mettre MXNestSpirit en ligne — 15 minutes

## 1. Compléter la licence
Ouvre https://www.gnu.org/licenses/gpl-3.0.txt, copie tout le texte, et colle-le
dans LICENSE à la place du bloc de fin. Garde les deux lignes de copyright en
haut, elles portent ton nom.

## 2. Créer le dépôt
- compte sur github.com si tu n'en as pas
- bouton New repository
- nom : mxnestspirit
- Public
- ne coche rien d'autre, Create

## 3. Déposer les fichiers
Sur la page du dépôt vide : "uploading an existing file", puis glisse :
- README.md
- LICENSE
- le dossier spiritpanel (tout son contenu, l'arborescence est conservée)
Commit changes.

## 4. Publier une version téléchargeable
- onglet Releases > Create a new release
- Tag : v1.0
- Titre : MXNestSpirit 1.0
- glisse le zip du panneau dans "Attach binaries"
- Publish release

Le lien de téléchargement direct devient :
https://github.com/TONCOMPTE/mxnestspirit/releases

## 5. Annoncer
Groupes Facebook de kits déco, forums MX, Instagram. Le message utile tient en
trois lignes : ce que ça fait, le métrage mesuré face à eCut, le lien.
