1. The nesting engine: a modified build of Sparrow 0.2.0
--------------------------------------------------------

Project:  https://github.com/JeroenGar/sparrow
Licence:  MIT. The licence as the project distributes it, with its copyright
          notice (Copyright (c) 2025 Jeroen Gardeyn, KU Leuven), is
          bin/SPARROW_LICENSE.txt. The same text is in section 5.1.
Shipped:  bin/sparrow (macOS, one universal file for x86_64 and arm64) and
          bin/sparrow.exe (Windows, x86-64).

The bundled engine is a modified build of Sparrow 0.2.0. It is built from the
upstream source at commit 9ef45676695ef94d045ac8bff0530822127f1437
(https://github.com/JeroenGar/sparrow/tree/9ef45676695ef94d045ac8bff0530822127f1437)
with two changes, both for upstream issue #160
(https://github.com/JeroenGar/sparrow/issues/160), a crash of the search:

  a) Upstream pull request #161 (https://github.com/JeroenGar/sparrow/pull/161),
     applied verbatim to src/eval/collision_loss.rs. An evaluation with no
     loss bound stays unbounded even when the accumulated loss overflows.

  b) Un repli dans src/optimizer/worker.rs. When the search returns
     no placement sample for an item, the item keeps its current position, a
     warning is logged once, and the run continues instead of stopping.
     Whether a layout is feasible is still decided by the engine's own
     collision check.

The complete change, as a unified diff against that commit, is the file
panic-fix-161.diff next to this file
(sha256 520242d8d638b5d3841c4c94392a0defaa7691a9731bc8715728a77633ba7fe6).
Build: rustc 1.100.0-nightly, release profile, no optional features, with
the dependency versions locked by the project's Cargo.lock. jagua-rs, every
crate in section 3 and the code in section 4 are used unmodified.

3. The other Rust crates statically linked into the engine
----------------------------------------------------------

The 84 crates below are compiled into the engine executables together
with Sparrow and jagua-rs. The list was produced with
"cargo tree -e normal,no-proc-macro --target <target> --offline --locked" on
the engine's source, which gives the dependencies the build compiles, for the
three shipped targets: aarch64-apple-darwin and x86_64-apple-darwin (the two
halves of bin/sparrow) and x86_64-pc-windows-gnu (bin/sparrow.exe). An entry
marked [macOS only] or [Windows only] is linked into that executable only;
[in: ...] names its targets. Procedural-macro crates, and the crates only
they use, run while the engine is compiled and are not part of the
executables, so they are not listed.

Each entry gives the crate, its version and the licence it is offered under,
then the copyright notice from the crate's own licence files, or its authors
where the crate names no holder. When a crate offers a choice of licences
(for example "MIT OR Apache-2.0"), the text of each licence offered is in
section 5.
